# แอปร้านต้นมะค่า แคมป์ปิ้งบาร์หมูกระทะ

เว็บแอปพลิเคชันหน้าร้านและหลังบ้านสำหรับพนักงาน/เจ้าของร้าน (`HTML + CSS + JS`) + เว็บมือถือให้ลูกค้าสแกน QR สั่งอาหาร — ทำงานบนเซิร์ฟเวอร์เดียวด้วย **Python (FastAPI + Uvicorn) + ฐานข้อมูล SQLite (`tonmakha.db`)** และใช้ฟอนต์ **Prompt** ทั้งระบบ (รวมถึงใบเสร็จ PDF) โดยไม่ต้องพึ่งพาอินเทอร์เน็ตหรือ CDN ภายนอก

## ติดตั้ง (ครั้งแรก)

> **ใช้ `python` หรือ `py`?** ขึ้นอยู่กับเครื่อง — Windows ที่ติดตั้ง Python จาก python.org มักใช้ `py` ได้เสมอ ส่วน macOS / Linux ส่วนใหญ่ใช้ `python3` หรือ `python`
> - **หลังเปิดใช้งาน `.venv` แล้ว ใช้ `python` ได้ทุกเครื่อง**
> - เอกสารนี้เขียนคำสั่งเป็น `python ...` ถ้ายังไม่ได้เปิด `.venv` และเครื่องของคุณใช้ `py` ให้เปลี่ยนเป็น `py ...`

1. ติดตั้ง Python 3.10 ขึ้นไปจาก python.org (ติ๊ก "Add Python to PATH" — **ไม่ต้องใช้ tcl/tk อีกต่อไป**)
2. เปิด Command Prompt / Terminal ในโฟลเดอร์โปรเจกต์ แล้วสร้างและเปิดใช้งาน Virtual Environment (`.venv`)

   **กรณีเครื่องใช้ `py` (Windows):**
   ```bash
   py -m venv .venv
   .venv\Scripts\activate
   ```
   **กรณีเครื่องใช้ `python` (Windows / macOS / Linux):**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate          # Windows
   source .venv/bin/activate        # macOS / Linux
   ```
   (macOS / Linux บางเครื่องต้องพิมพ์ `python3 -m venv .venv`) เมื่อสำเร็จ หน้าบรรทัดคำสั่งจะมี `(.venv)` นำหน้า
   > ถ้า PowerShell ขึ้น error ว่าสั่ง activate ไม่ได้ ให้รัน `Set-ExecutionPolicy -Scope Process Bypass` ก่อน แล้ว activate อีกครั้ง
3. ติดตั้งไลบรารี
   ```bash
   pip install -r requirements.txt
   ```
4. สร้างไฟล์ตั้งค่า `.env` จากไฟล์ตัวอย่าง (รายละเอียดการกรอกค่าอยู่ในหัวข้อ "ระบบสมาชิกลูกค้าและ OTP" ด้านล่าง)
   ```bash
   copy .env.example .env      # Windows (Command Prompt)
   cp .env.example .env        # macOS / Linux / Git Bash
   ```
5. ตรวจสอบความพร้อมของระบบ (ไลบรารี, ฐานข้อมูล 17 ตาราง, ฟอนต์ Prompt 18 ไฟล์, ไฟล์ Frontend, PromptPay QR)
   ```bash
   python main.py --check
   ```
6. เปิดเซิร์ฟเวอร์และเบราว์เซอร์หน้าร้าน
   ```bash
   python main.py
   ```
   - ระบบจะเปิดเซิร์ฟเวอร์เดียว (ค่าเริ่มต้นพอร์ต `8080`) และเปิดเบราว์เซอร์ไปยังหน้าพนักงาน/เจ้าของร้าน `http://127.0.0.1:8080/staff` โดยอัตโนมัติ
   - ครั้งแรกระบบสร้างฐานข้อมูล `tonmakha.db` + ข้อมูลตัวอย่าง (10 โต๊ะ, เมนู, สต๊อก) ให้เอง หากมีฐานข้อมูลเดิมอยู่แล้ว ระบบจะรัน migration อัปเกรดตารางและค่าเริ่มต้นใหม่อัตโนมัติโดยไม่ลบข้อมูลเก่า
   - ถ้าไม่ได้เปิด `.venv` และเครื่องใช้ `py` ให้พิมพ์ `py main.py --check` และ `py main.py` แทน

> **หมายเหตุ:** หน้า `/staff` เปิดได้เฉพาะเครื่องที่รันเซิร์ฟเวอร์เท่านั้น (ดูหัวข้อด้านล่าง) จึงออกแบบมาให้รันบนเครื่องของร้านหรือเครื่องที่ใช้ตรวจงาน ไม่เหมาะกับการ deploy ขึ้นเว็บโฮสต์

บัญชีเริ่มต้น (**ต้องเปลี่ยนรหัสผ่านก่อนใช้งานจริง** ที่เมนู เจ้าของร้าน → ผู้ใช้): `owner / owner1234`, `staff1 / staff1234`

## เส้นทาง URL และความปลอดภัยของหน้าพนักงาน/เจ้าของร้าน
| เส้นทาง URL | สำหรับใคร | รายละเอียด |
|---|---|---|
| `http://127.0.0.1:8080/staff` | พนักงาน / เจ้าของร้าน | เว็บแอปจัดการหน้าร้านและหลังบ้าน (`#/tables`, `#/weigh`, `#/orders`, `#/checkout`, `#/dashboard`, `#/menu`, `#/stock`, `#/promo`, `#/tables_manage`, `#/users`, `#/settings`, `#/log`, `#/backup`) |
| `http://<IP เครื่องร้าน>:8080/t/<เลขโต๊ะ>?k=<รหัสลับ>` | ลูกค้า (สแกน QR) | หน้าเข้าโต๊ะจาก QR (ตรวจสอบด้วย POST ฝั่ง JS เพื่อกันบอตพรีวิวลิงก์ของ LINE/Facebook สร้างรอบหลอก แล้วล้าง `?k=` ออกจาก URL ทันที) |
| `http://<IP เครื่องร้าน>:8080/s` | ลูกค้า | หน้าหลักของลูกค้า สลับมุมมองตามสถานะรอบ (`waiting` / `order` / `bill` / `closed` / `cancelled`) โพลทุก 3 วินาที |
| `http://<IP เครื่องร้าน>:8080/` | ลูกค้า | หน้าแจ้งให้สแกน QR ที่โต๊ะ |

### การจำกัดวงเครื่องที่เข้าหน้าพนักงาน/เจ้าของร้าน (`/staff`)
- โดยค่าเริ่มต้น `/staff`, `/api/staff/*` และ `/api/owner/*` **อนุญาตให้เข้าได้เฉพาะเบราว์เซอร์บนเครื่องที่รันเซิร์ฟเวอร์เท่านั้น (`127.0.0.1` / `::1`)** และจะปฏิเสธคำขอที่มี Proxy/Tunnel Header (`X-Forwarded-For`, `Forwarded`, `CF-Connecting-IP`) เพื่อป้องกันไม่ให้ลูกค้าในวง Wi-Fi หรือผ่านลิงก์ภายนอกเข้าหน้าล็อกอินของร้านได้
- หากร้านต้องการอนุญาตเครื่องแคชเชียร์อื่นในวง LAN เพิ่มเติม สามารถกำหนดวงเครือข่ายที่อนุญาตใน `STAFF_ALLOWED_NETS` ของ `config.py` หรือคีย์ `staff_allowed_nets` ในตาราง `settings`

## ตั้งค่าครั้งแรก (เจ้าของ)
1. **ตั้งค่า → ลิงก์เว็บลูกค้า**: ใส่ `http://<IP เครื่องร้าน>:8080` (หน้าตั้งค่าแสดง IP ให้และมีปุ่ม "ใช้ค่านี้") — มือถือลูกค้าต้องต่อ Wi-Fi เดียวกับเครื่องนี้
2. Windows จะถามเรื่อง Firewall ตอนเปิดครั้งแรก ให้กด **อนุญาต** (พอร์ต 8080)
3. **จัดการโต๊ะ/QR → สร้าง QR ทุกโต๊ะ** แล้วดาวน์โหลดหรือพิมพ์ไฟล์ QR ติดโต๊ะ (เปลี่ยนลิงก์หรือสุ่มรหัสลับใหม่ทีหลังต้องสร้าง/พิมพ์ QR ใหม่)
4. **ตั้งค่า → การรับชำระเงิน PromptPay และอัตราราคาชั่งกิโล**:
   - **หมายเลข PromptPay**: ค่าเริ่มต้นเป็นเบอร์ตัวอย่าง `0800000000` ให้เปลี่ยนเป็นของร้านจริง (รองรับเบอร์มือถือ 10 หลัก หรือเลขบัตรประชาชน/เลขผู้เสียภาษี 13 หลัก)
   - **ชื่อบัญชีเจ้าของร้าน**: ค่าเริ่มต้นเป็นชื่อตัวอย่าง `ชื่อ นามสกุล` ให้เปลี่ยนเป็นชื่อบัญชีจริง (ใช้แสดงบนหน้าชำระเงินให้พนักงานตรวจสอบก่อนรับโอน)
   - **ราคาชั่งกิโล**: ค่าเริ่มต้น `299` บาท/กก. (ซิงก์กับหน้าชั่งน้ำหนักและใบเสร็จโดยอัตโนมัติ)
5. **ตั้งค่า → แจ้งเตือนโต๊ะเงียบ และ เกณฑ์สต๊อกใกล้หมด**:
   - **เกณฑ์สต๊อกใกล้หมดเริ่มต้น**: ค่าเริ่มต้น `5` หน่วย (แก้ไขได้ และสามารถตั้งจุดเตือนเฉพาะรายสินค้าได้ที่หน้าสต๊อก)
   - แถบแดงแจ้งเตือนด่วน (`AlertCenter`) แสดงแจ้งเตือนโต๊ะเงียบและสต๊อกใกล้หมด/หมด พร้อมเสียงเตือน WebAudio (มีปุ่มเปิด/ปิดเสียงที่แถบบน)
6. **เมนูและราคา / รูปภาพเมนู / สต๊อก / โปรโมชั่น**:
   - เจ้าของร้านอัปโหลด/เปลี่ยน/ลบรูปภาพเมนู (JPG, PNG, WebP ขนาดไม่เกิน 5 MB) ได้ที่หน้า **เมนูและราคา** ระบบจะปรับสัดส่วน 1:1 (Square) อัตโนมัติ
   - หน้า **สต๊อก** มีปุ่ม **ลบรายการสต๊อก** แยกจากปุ่มเติม/ปรับจำนวน โดยระบบตรวจผลกระทบก่อนลบและป้องกันข้อมูลประวัติเสียหาย
7. กด **เปิดร้าน** ที่แถบบนขวา — ลูกค้าถึงจะสแกนเข้าได้

## ระบบสมาชิกลูกค้าและ OTP
ลูกค้าสามารถสแกน QR สั่งอาหารได้ทันทีโดยไม่จำเป็นต้องสมัครสมาชิก แต่หากสมัครสมาชิกจะสามารถเก็บ/ใช้โค้ดส่วนลดพิเศษสำหรับสมาชิกและดูประวัติใบเสร็จย้อนหลังได้ โดยระบบยืนยันตัวตนด้วย **รหัส OTP 6 หลักทางอีเมลจริง** เท่านั้น (ไม่มีการแสดงรหัส OTP บนหน้าจอหรือใน API response)

### 1. วิธีสร้าง Gmail App Password (รหัสผ่านสำหรับแอป 16 ตัวอักษร)
1. เข้าไปที่หน้าจัดการบัญชี Google (`https://myaccount.google.com/security`) ของอีเมลร้านที่จะใช้ส่ง OTP
2. เปิดใช้งาน **การยืนยันแบบ 2 ขั้นตอน (2-Step Verification)** ให้เรียบร้อยก่อน
3. ค้นหาเมนู **รหัสผ่านสำหรับแอป (App passwords)**
4. ตั้งชื่อแอป (เช่น `Tonmakha BBQ OTP`) แล้วกดสร้าง ระบบจะแสดงรหัสผ่าน 16 ตัวอักษร ให้คัดลอกรหัสนี้ไว้ใส่ใน `SMTP_PASSWORD` (ห้ามใช้รหัสผ่านเข้าอีเมลปกติ)

### 2. วิธีคัดลอก `.env.example` เป็น `.env` และกรอกค่าตั้งค่า
1. ใช้ไฟล์ `.env` ที่คัดลอกจาก `.env.example` ในขั้นตอนติดตั้งข้อ 4 (ถ้ายังไม่ได้ทำ: `copy .env.example .env` บน Windows หรือ `cp .env.example .env` บน macOS / Linux)
2. เปิดไฟล์ `.env` แล้วกรอกข้อมูลให้ครบถ้วน:
   - `SMTP_HOST=smtp.gmail.com` และ `SMTP_PORT=587` (STARTTLS) หรือ `465` (SSL)
   - `SMTP_USER=` อีเมล Gmail ของร้าน (เช่น `tonmakha.shop@gmail.com`)
   - `SMTP_PASSWORD=` รหัส App Password 16 ตัวอักษรจากขั้นตอนที่ 1
   - `SMTP_FROM_NAME=` ชื่อผู้ส่งที่แสดงในหัวอีเมล (เช่น `ต้นมะค่า แคมป์ปิ้งบาร์หมูกระทะ`)
   - `SMTP_FROM=` เว้นว่างไว้เพื่อใช้ค่าเดียวกับ `SMTP_USER` (หรือหากระบุต้องเป็นบัญชีเดียวกับ `SMTP_USER`)
   - `OTP_SECRET=` คีย์ลับสำหรับแฮช OTP ด้วย HMAC-SHA256 (ความยาวอย่างน้อย 32 ตัวอักษร) สร้างได้ด้วยคำสั่ง (เครื่องที่ใช้ `py` ให้พิมพ์ `py -c ...`):
     ```bash
     python -c "import secrets; print(secrets.token_urlsafe(48))"
     ```
   - `MEMBER_DEMO_ACCOUNTS=0` (ตั้งเป็น `0` ในการใช้งานจริงเพื่อปิดบัญชีตัวอย่าง; ตั้งเป็น `1` เฉพาะตอนต้องการเปิดบัญชีตัวอย่างสำหรับพัฒนา/ทดสอบ)
3. รัน `python main.py --check` เพื่อตรวจสอบว่าระบบอ่านค่า `SMTP` และ `OTP_SECRET` เรียบร้อยแล้ว

### 3. วิธีทดสอบส่ง OTP จริง (สมัครสมาชิก และ ลืมรหัสผ่าน)
- **สมัครสมาชิกใหม่ (2 ขั้นตอน):**
  1. บนหน้ามือถือลูกค้า (`/s` เมื่อโต๊ะเปิดใช้งาน) กดปุ่ม **สมัครสมาชิก**
  2. ขั้นที่ 1/2: กรอกชื่อ, อีเมลจริงของคุณ, เบอร์โทรศัพท์ไทย และรหัสผ่าน (อย่างน้อย 8 ตัวอักษร ไม่เกิน 72 ไบต์ และไม่ซ้ำกับอีเมล) แล้วกด **รับรหัส OTP ทางอีเมล**
  3. ขั้นที่ 2/2: เปิดอีเมลที่ได้รับ นำรหัส OTP 6 หลักมากรอกภายใน 10 นาที แล้วกด **ยืนยันและสมัครสมาชิก**
- **ลืมรหัสผ่าน / ตั้งรหัสผ่านใหม่ (2 ขั้นตอน):**
  1. ที่หน้า **เข้าสู่ระบบ** กดลิงก์ **ลืมรหัสผ่าน?**
  2. ขั้นที่ 1/2: กรอกอีเมลที่ใช้สมัครสมาชิกแล้วกด **รับรหัส OTP ทางอีเมล**
  3. ขั้นที่ 2/2: กรอกรหัส OTP 6 หลักจากอีเมล พร้อมกำหนดรหัสผ่านใหม่และยืนยันรหัสผ่านใหม่ แล้วกด **ตั้งรหัสผ่านใหม่** (เมื่อเปลี่ยนรหัสผ่านสำเร็จ เซสชันที่เคยล็อกอินค้างไว้ในเครื่องอื่นจะถูกยกเลิกอัตโนมัติทันที)

### 4. ข้อควรรู้ในการรับอีเมล OTP
- อีเมลแจ้งรหัส OTP อาจถูกจัดเข้าไปอยู่ในโฟลเดอร์ **จดหมายขยะ (Spam / Junk)** หรือแท็บโปรโมชั่น และอาจใช้เวลาส่งประมาณ 5–60 วินาทีขึ้นอยู่กับผู้ให้บริการอีเมล
- รหัส OTP มีอายุการใช้งาน **10 นาที** ใช้ได้ครั้งเดียว และหากกดขอรหัสใหม่ รหัสฉบับเก่าจะถูกยกเลิกทันที (ต้องใช้รหัสจากอีเมลฉบับล่าสุดที่ขอเท่านั้น)
- ขอส่งรหัสซ้ำได้เมื่อครบ **60 วินาที** และขอได้ไม่เกิน **5 ครั้งต่อชั่วโมง** ต่ออีเมล

## การชำระเงินและใบเสร็จรับเงิน (PDF / TXT / พิมพ์)
- ช่องทางชำระเงินมี 2 รูปแบบ: **เงินสด** (คำนวณเงินทอนสดด้วย `Decimal` และห้ามยืนยันถ้ารับเงินน้อยกว่ายอดสุทธิ) และ **โอน/PromptPay** (สร้าง QR EMVCo ระบุยอดอัตโนมัติ แสดงสถานะ `รอตรวจสอบการโอน`)
- หลังชำระเงินจะมีหน้าต่างใบเสร็จรับเงินจัดย่อหน้าด้วยฟอนต์ **Prompt** พร้อมปุ่ม **บันทึก PDF (.pdf)**, **บันทึก TXT (.txt)** (บันทึกไว้ที่ `exports/` และดาวน์โหลดผ่านเบราว์เซอร์ได้ทันที) และปุ่ม **พิมพ์** (`window.print()`)

## ตัวเลือกการเปิดและการรันทดสอบ
(ตารางนี้เขียนเป็น `python` — ถ้าเครื่องใช้ `py` และไม่ได้เปิด `.venv` ให้เปลี่ยนเป็น `py`)

| คำสั่ง | ความหมาย |
|---|---|
| `python main.py` | เปิดเซิร์ฟเวอร์ (ค่าเริ่มต้น `0.0.0.0:8080`) + เปิดเบราว์เซอร์หน้า `/staff` |
| `python main.py --no-browser` | เปิดเซิร์ฟเวอร์โดยไม่เปิดหน้าต่างเบราว์เซอร์อัตโนมัติ |
| `python main.py --host 0.0.0.0 --port 8080` | กำหนด host และ port เอง |
| `python main.py --check` | ตรวจสอบความพร้อมของระบบทั้งหมด (ไลบรารี, DB 17 ตาราง, ฟอนต์ Prompt, Frontend, PromptPay, SMTP/OTP_SECRET, รหัสผ่านเริ่มต้น) |
| `python run_web.py [--port 8080]` | ทางลัดเทียบเท่า `python main.py --no-browser` เพื่อความเข้ากันได้ |
| `python -m unittest discover -s tests -v` | รันชุดทดสอบอัตโนมัติทั้งหมด (เทสต์เดิม + เทสต์ API + เทสต์ความปลอดภัย + เทสต์สมาชิก/OTP + เทสต์ E2E เบราว์เซอร์) |
| `python tools/ui_audit.py` | รันตัวตรวจการจัดวาง ตาราง การ์ด ขอบซ้าย และฟอนต์ Prompt อัตโนมัติ (สร้างรายงานที่ `docs/ui_audit.md`) |

## สำรอง/กู้คืนข้อมูลและข้อควรระวังด้านความปลอดภัย
- สำรองอัตโนมัติวันละครั้งตอนเปิดแอป (เก็บ 14 ไฟล์ล่าสุด) ไว้ที่ `backups/` ; เจ้าของกด **สำรองตอนนี้** และ **ดาวน์โหลด** ไฟล์สำรองได้ที่หน้า **สำรองข้อมูล**
- กู้คืนได้เมื่อปิดร้านและไม่มีโต๊ะค้าง (ต้องพิมพ์คำว่า `กู้คืน` ยืนยัน) ; ระบบสำรองข้อมูลปัจจุบัน (`prerestore`) ไว้ให้ก่อนเสมอ
- **ห้ามแชร์หรือนำไฟล์ลับต่อไปนี้ขึ้น Git สาธารณะเด็ดขาด**: `.env`, `web_secret.key`, `tonmakha.db` (`*.db`), โฟลเดอร์ `backups/`, และ `assets/qr_codes/` (ถูกกันไว้ใน `.gitignore` แล้ว)
